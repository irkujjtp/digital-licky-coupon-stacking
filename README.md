首单券的实际折扣可以自己算一遍。满 ¥39 减 ¥5，实付 34，相当于 8.7 折；满 ¥29 减 ¥2，实付 27，相当于 9.3 折。两个门槛之间只差 10 元，多减的却只有 3 元，为了从 29 凑到 39 再买一件用不上的东西，等于多花钱买了个更低的折扣数字。

积分的加赠也有边界。会员日是每月 7 日，当天消费按 1.2 倍计，加赠部分每 ¥100 多给 20 分，当日累计赠送上限 200 分。换算下来，当天消费超过 ¥1000 之后，加赠就不再增加了。所以大额订单扎堆在会员日并不划算，把几笔小额订单放到 7 日下，收益更明显。

券与券之间不叠加。首单结算时系统会自动使用符合门槛的最高面额券，另一张直接失效，别想着把 ¥2 和 ¥5 分两单用掉。首单只有一次，用在最贵的那件上更合理。下单前以结算页显示为准。

## 这里没有“套餐”，下单前要看清三件事

数码荔枝是正版软件授权零售商，不是卖订阅套餐的 SaaS。站内按 Windows 和 Mac 分区，手机端另分 iOS 与 Android，同一款软件在不同平台往往是分开的商品，各自定价。买之前先确认自己要用的是哪个平台，这一步错了，后面所有优惠都白搭。

第二件是授权形式。站内以买断制为主，很多商品标着“终生版”，一次付清、长期可用；也有订阅类商品，比如 Office 365 这类按年计费的，以及 Windows 系统授权。买断和订阅在页面上的呈现方式不一样，看清楚是“一次付清”还是“每年续费”，两者的长期成本差得很远。

第三件是设备数。同一款软件常有单设备、2 台、3 台、5 台等不同授权规格，价格随设备数上升。家里一台电脑加一台笔记本，就得买覆盖 2 台的版本，买单设备版再想办法“共享”通常违反授权条款。

标价跨度也很大，站内单款软件从十几元的小工具到几百元的生产力软件都有，同一款软件的不同设备数版本价格又不一样。看到别人晒的“我买才 XX 元”，先确认他买的是哪个平台、几台设备。

## 几个容易踩的坑

最实在的一个坑是首单券只有一次机会。不少人拿它去买了十几块钱的小工具，等真正想买几百块的软件时，券已经没了。规则里写得很清楚，两张首单券二选一，结算自动用掉，另一张失效。

第二个坑是专属码的有效期。博主发出来的 9.5 折、9 折码，几乎都绑定某一轮活动，过期后结算页直接报错。看到旧文章里的码，先看它配套的活动结束没有，别为了等一个不存在的码错过正在进行的活动价。

第三个坑在授权规格上，平台选错和设备数买少都是常见失误。退款这块我没找到统一口径，商品页和结算页各软件的说明并不一致，所以下单前那一步的核对最值得花时间。

第四个坑是红包返现要主动参与。它不会自动到账，得关注公众号、设为星标、私信回复 666，流程走完才算数。每笔订单都能参与，忘了就是白丢。
